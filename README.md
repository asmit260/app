# AniTrack — Mobile App

A modern anime schedule tracker, watchlist manager, and AI anime advisor built with React, Vite, TailwindCSS, and Capacitor.

## Features
- 📅 Weekly Airing Schedule with live countdown timers
- 🧭 Explore trending news & curated 49 Hidden Gems
- 📋 Watchlist management with quick +1 episode logging
- 📊 Personal anime statistics & watch streak tracker
- ⚔️ Captain Levi AI anime assistant

## Development
```bash
npm install
npm run dev
```

## Android APK Build
The repository includes a GitHub Actions workflow (`.github/workflows/build-apk.yml`) that automatically builds and publishes the debug APK upon each push.
